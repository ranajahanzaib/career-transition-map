# Occupation crosswalks

CPS Census occupation codes, Standard Occupational Classification, O\*NET-SOC, and BLS National Employment Matrix codes have different scopes and taxonomies. A numeric code match alone is not proof of equivalent occupation meaning.

Crosswalk records must preserve source and destination classification versions, codes, relationship type, applicable period, provenance, quality, and limitations. One-to-many relations must not duplicate a CPS person or weight. Ambiguous codes remain unmapped or are aggregated to a defensible common level. Never select the first matching detailed O\*NET occupation without evidence.

The current release does not include a versioned crosswalk. CPS transition cells therefore remain in Census occupation codes and are not joined to O\*NET profiles.
