# Network methodology

Observed mobility and profile similarity are distinct edge types. A directed transition edge points from the retrospective origin occupation to the current destination; retention/self-loops are retained only if release questionnaire coding supports them. Similarity edges do not imply observed movement.

Every network artifact should carry release, classification, edge-definition, reliability, and layout versions. Degree or bridge metrics are descriptive properties of the selected published graph and are not measures of worker access, career desirability, or causal effect. Multi-edge pathways are constructed paths; they do not claim the sequence occurred for one worker.

The current release does not include a mobility or skill-similarity network. Network metrics and multi-step pathways are therefore not reported.
