# Visualization system

The web interface uses semantic HTML, CSS, and an explicitly illustrative SVG network shape on the overview page. The illustration contains no research nodes, edges, counts, or scores. The published transition cells and profile ratings are available in tabular views; unavailable analyses are identified in their views.

The current release does not include a data-backed network graph. Mobility, profile similarity, projections, and wages are separate evidence types and are not combined in its visualizations.
